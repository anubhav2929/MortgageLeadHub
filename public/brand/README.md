# Equity Flow Group brand assets

All logo and icon files in this directory have transparent backgrounds.

- `logo-primary.svg` / `logo-primary.png`: primary horizontal lockup for light backgrounds.
- `logo-reversed.svg` / `logo-reversed.png`: reversed horizontal lockup for dark backgrounds.
- `logo-mark.svg`: scalable symbol for compact UI and print use.
- `logo-mark-192.png` / `logo-mark-512.png`: transparent app-icon exports.
- `icons/*.svg`: the home equity, growth, flow, and trust symbol set.

Core palette: deep green `#0E6B4F`, bright green `#22A06B`, ink `#111918`, slate `#64706B`, and off-white `#F7F8F6`. Typography is Satoshi, self-hosted by the application.
